# Evidence-Only Rules

1. Deterministic evidence is the source of truth.
2. Every technical claim must be traceable to evidence.
3. Do not infer business workflows from method names alone.
4. Mark external boundaries as candidate unless another repo confirms them.
5. If evidence is missing, add an open question.
6. Do not read or assume original TypeScript source.
7. Do not generate Atomic PRDs in this task.
