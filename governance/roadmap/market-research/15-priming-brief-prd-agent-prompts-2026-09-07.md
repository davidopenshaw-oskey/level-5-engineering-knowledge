# Priming Brief — Real Examples of Prompts Used to Have an LLM Build a PRD

**Purpose of this file:** hand this to a fresh Claude session as its first message (or tell it to read this file first). This is a research/report task — do not modify any file in this repository other than writing your own findings report (location at the bottom).

## What to actually research

**Search live, on the open web, for real, current examples — do not answer from training knowledge alone.** Verify anything you report with a real source, and cite it.

Find real, current prompts/personas/system-instructions that people or products actually use to have an LLM produce a PRD (or a close equivalent — a spec, a technical proposal document).

**Prefer, most of all, an example built on the same real structure this project uses**: search for evidence first (tool calls against a real data/code source), then assemble the document from what the search actually returned — rather than a prompt that just asks the model to write a PRD from general knowledge or a short description alone.

If something isn't found, say so directly rather than padding with speculation.

## What a genuinely useful report looks like

Name the real examples found, with sources, and quote or closely paraphrase their actual prompt/instruction text where possible.
