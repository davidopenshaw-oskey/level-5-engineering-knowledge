# Historic workflow examples and ideas

## In an earlier research, we used chatGpt and notebookLM in researching how the existing context docs and source code knowledge could be used to:-

- first build a candidate list of workflows
- verify with human the workflows

This was a way of semi-automating and seeding the system with as many workflows as possible.

## Why we stopped

The work stopped because we decided that the P1 pipeline should be based on AST facts instead of throw the repo at an LLM to get the facts.
