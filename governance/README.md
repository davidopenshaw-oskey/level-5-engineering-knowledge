# Knowledge Governance (`/governance`)

This directory houses the foundational charters, quality standards, architectural decision records, and source codebase reference specifications governing the Level 5 Engineering Knowledge platform.

---

## Subdirectories

- [`adrs/`](file:///Users/dopenshaw/documentation/level-5_engineering_knowledge/governance/adrs/): Architectural Decision Records capturing pipeline evolution (`adr-000.md`, `adr-001.md`).
- [`charters/`](file:///Users/dopenshaw/documentation/level-5_engineering_knowledge/governance/charters/): Phase execution charters defining vision, scopes, and verification criteria.
- [`reference-docs/`](file:///Users/dopenshaw/documentation/level-5_engineering_knowledge/governance/reference-docs/): Static architecture specifications, Firestore rules, and RBAC matrix definitions from target repositories.
